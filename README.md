# Scrunchies-Villa :

Live Demo: https://scrunchiesvilla.vercel.app/

Scrunchies Villa is a full-stack web application for an online scrunchies store.  
Users can browse products, add items to cart, and place orders easily.

##  Features
- 🛍️ Browse scrunchies products
- 🛒 Add to cart functionality
- 💳 Order management
- 👤 User-friendly interface
- 📱 Responsive design (mobile + desktop)
